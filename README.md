# This is an original Android auto-clicker project inspired by the functionality commonly found in game automation apps.
# It is not a direct copy of any existing Play Store app.

## Features
- Auto tap / auto click engine
- Adjustable delay between taps
- Tap coordinate setting (x, y)
- Start/stop floating button overlay
- AccessibilityService integration
- Java + XML Android project

## Important notes
- This app requires Accessibility Service permission to send taps.
- Overlay permission is required to show the floating button.
- This app is intended for testing and personal use; check local laws and app-store policies before publishing.

## Build instructions
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Connect an Android device or start an emulator.
4. Run the app.

## Setup steps in app
1. Tap "Enable Accessibility" and enable Auto Clicker Game in Accessibility settings.
2. Tap "Show Floating Button" and allow overlay permission.
3. Enter delay and target coordinates.
4. Toggle the switch or use the floating button to start/stop auto-clicking.
